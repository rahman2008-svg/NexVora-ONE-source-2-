# NexVora ONE

**Build Anything. Anywhere.**

NexVora ONE is an Android development studio built on top of the open-source
[Acode](https://github.com/Acode-Foundation/Acode) editor (MIT). It keeps Acode's working engines
(CodeMirror editor, file explorer, terminal + proot Linux, SFTP/FTP, local preview server, plugin system)
and adds a NexVora design system, a Home dashboard, and an ad-free, purchase-free build.

- App ID: `com.nexvora.one` - Version `1.0.0`
- Developed by Prince AR Abdur Rahman - Published by NexVora Lab's Ofc

> **Honest status:** see [FEATURES.md](FEATURES.md). Several studios from the original product spec
> (Git, AI, Database, API, Deploy, Toolbox, ...) are **not implemented yet** and are shown on the
> dashboard as "Soon". Nothing in this repository has been built into an APK or run on a device
> by the author of this change set; the CI workflow is the intended build path.

## Quick start
See [BUILD.md](BUILD.md). In short: push to GitHub and run the **NexVora ONE - Android Build** workflow, or
build locally with Node 22, JDK 21 and the Android SDK (`npm run setup && npm run build -- d apk`).
